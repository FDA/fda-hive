hlp.svc-popul.html HIVE Hexahedron Coordinated Clonal Analysis The HIVE Hexahedron Coordinated Clonal Analysis tool renders visualization of all possible subclones contained in a single sample. Subclones are computed by reconstruction of an arbitrary number of haplotypes from NGS data and reported with corresponding relative frequencies. This analysis is ideal for application to viral samples, particularly RNA viruses. This workflow may also be useful to distinguish between subclonal populations of tumors.


Basic inputs and parameters:
    Name
    Specify a name for the analysis output object.

    Alignment(s)
    Here you must specify the previously-computed alignment file for the reads (as discussed in the previous section).

    Paired End Reads
    Specify whether the data are in the form of paired-end or single reads by choosing the appropriate option from the dropdown menu. Use of paired-end reads allows the algorithm to quickly identify regions of high similarity when assigning members of pairs. Note that order is important; pairs must be organized such that the first reads of each pair are listed together followed by the list of all the second reads of each pair in the same order of pairs.

    Threshold for Bifurcation Call (percentage)
    Define a frequency above which a mutation constitutes a separate clone. Default is set to 5 percent.

    Reference Genome Alignment File
    Here, you must specify the previously-computed multiple-alignment file for the reference (as discussed in the previous section).

    Batch Service
    Choose "Batch Mode" from the dropdown menu to launch multiple Hexahedron computations simultaneously. By default, all proceses are launched in single computation mode. For more information, please see the specific batch help documentation.
