hlp.svc-popul.html HIVE Hexahedron Coordinated Clonal Analysis The HIVE Hexahedron Coordinated Clonal Analysis tool renders visualization of all possible subclones contained in a single sample. Subclones are computed by reconstruction of an arbitrary number of haplotypes from NGS data and reported with corresponding relative frequencies. This analysis is ideal for application to viral samples, particularly RNA viruses. This workflow may also be useful to distinguish between subclonal populations of tumors.


Advanced inputs and parameters:
    Bifurcate based on
    Designate the criterion for a bifurcation event from frequency, pvalue, or bayes. The default is set to frequency.

    Clone swap
    If selected, this option will automatically swap a clone to the predominant clone (that with the higher coverage) in the frame. This swap is turned off by default.

    Threshold of fuzzy regions
    Because of the way the alignments are brought to the sliding frame from left to right, coverage drops off significantly after a certain point (unique to each experiment). This percentage allows the user to specify the minimum percentage of the mutation threshold for which a bifurcation event can be called, taking into account this fuzziness. For instance, if this parameter is set to 75% and the mutation threshold is set to 2%, then the threshold to call a bifurcation is 75% of 2%, or 1.5%, with respect to the depth of coverage across all frames covering that position. Default is set to 50%.

    Minimum overlap of sliding window
    Specify the minimum number of nucleotide positions, with respect to the reference alignment frame, required to overlap between adjacent frames. Minimum set to 100 bases.

    Ignored gap threshold (percentage)
    Specify the minimum percentage of coverage with respect to the average coverage at a gapped position in the reference multiple alignment required to ignore the gap and call a contig at the position. Default set to 5%.

    Force continuity
    Consider reads extending around gapped regions to be continuous, therefore maintaining the positional coordinates of the refereces. Default is set to yes.

    Noise
    The value is dynamically generated based on entropy calculations from alignments. Default set to 3.

    Trees
    The parameters below allow the user to specify properties of trees corresponding to the phylogeny of reported clones. By default, trees are not computed as this is a computationally heavy request.
    • Tree size: Specify the maximum number of reads to be sampled for each frame
    • Width of tree frame: Specify the width of the tree frame as the number of nucleotide positions to consider within a single frame
    • Step of tree frame: Specify the step of the tree frame as the number of bases between the beginnings of adjacent frames
    • Minimum overlap in tree frame: Designate the minimum number of overlapping positions between adjacent tree frames
    • Trees from the population frames: If selected, the tree builder will us ethe same frames automatically generated for the clone expansion computation for the tree building algoright. By default, this option is turned off
    • Generate trees: This option must be selected in order to generate and view trees for the identified clones. By default, trees are not generated
